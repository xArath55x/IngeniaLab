Verificacion
Los tres procedimientos revisan los 166 archivos. Tome SHA256SUMS.txt de la rama it-2.
El conteo debe dar 166: los hashes no detectan archivos de mas. Hagalo antes de
instalar, porque el lanzador agrega .venv, db.sqlite3 y otros archivos locales.
En Linux use sha256sum -c SHA256SUMS.txt si no tiene shasum.

A. Copia obtenida de Git (Linux o macOS, desde la raiz de un clon)
  d=$(mktemp -d)
  git archive release/v2.0 | tar -x -C "$d"
  cp evidencia/ACT225/SHA256SUMS.txt "$d/"
  cd "$d"
  shasum -a 256 -c SHA256SUMS.txt
  find . -type f ! -name SHA256SUMS.txt | wc -l

B. ZIP descargado de GitHub (Linux o macOS)
Descargue https://github.com/xArath55x/IngeniaLab/archive/refs/tags/release/v2.0.zip,
descomprimalo y copie SHA256SUMS.txt dentro de la carpeta IngeniaLab-release-v2.0.

C. ZIP descargado de GitHub (Windows, PowerShell)
Prepare la carpeta como en B y ejecute dentro de ella. No se ha probado en Windows.
  Get-Content SHA256SUMS.txt | ForEach-Object {
    $hash, $ruta = $_ -split '  ', 2
    if ((Get-FileHash -LiteralPath $ruta -Algorithm SHA256).Hash -ne $hash) { "FALLA: $ruta" }
  }
  (Get-ChildItem -Recurse -File -Exclude SHA256SUMS.txt).Count

C no debe mostrar ninguna linea FALLA. No verifique un clon de Windows directamente:
una conversion de fin de linea puede cambiar los hashes sin que el contenido en Git
cambie. Por eso se usa git archive o el ZIP.
