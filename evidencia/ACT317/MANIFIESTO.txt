Verificacion
Los tres procedimientos revisan los 200 archivos desde la carpeta raiz de la
copia. El conteo debe dar 200: los hashes no detectan archivos de mas. Hagalo
antes de instalar, porque el lanzador agrega .venv, db.sqlite3 y otros archivos
locales. En Linux use sha256sum -c si no tiene shasum.

C. ZIP descargado de GitHub (Windows, PowerShell)
Prepare la carpeta como en B y ejecute dentro de ella. Es el procedimiento C de
ACT-225, que se probo en Windows 10 en ACT-312 (0 lineas FALLA).
  Get-Content evidencia\ACT317\SHA256SUMS.txt | ForEach-Object {
    $hash, $ruta = $_ -split '  ', 2
    if ((Get-FileHash -LiteralPath $ruta -Algorithm SHA256).Hash -ne $hash) { "FALLA: $ruta" }
  }
  (Get-ChildItem -Recurse -File | Where-Object {
    $_.FullName -notlike '*\evidencia\ACT317\SHA256SUMS.txt' -and
    $_.FullName -notlike '*\evidencia\ACT317\MANIFIESTO.txt' }).Count

C no debe mostrar ninguna linea FALLA. No verifique un clon de Windows directamente:
una conversion de fin de linea puede cambiar los hashes sin que el contenido en Git
cambie. Por eso se usa git archive o el ZIP.
